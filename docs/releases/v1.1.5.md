v1.1.4 的补丁版本：回答里可以画图，智能 UI 新增「选项」卡片。

*English summary below.*

## 新功能

- **Mermaid 图表。** 回答里的 `mermaid` 代码块会画成图：流程图、时序图、层级结构等。图和代码块用同一套外框，右上角可以在「图表」和「代码」之间切换、复制源码，深色模式下跟着换配色。回答还在输出时先显示代码，写完再画；语法有误时显示源码并说明画不出来。Mermaid 只在第一次遇到图表时才加载，不影响平时的页面速度。系统提示词里告诉模型这种代码块会画成图，用不用由它判断。
- **智能 UI 的「选项」卡片。** 开着后台「智能 UI」时，模型可以在回答末尾给出几个接下来可以深入的方向。每个选项是一条模型事先写好的完整消息，选中后点按钮就以你的身份发出，和在输入框里发送一样（照常经过内容审核，游客模式也能用）。只有最后一条回答里的选项能点；发出后卡片保留，并标出选的是哪一项。要不要给选项由模型自己判断。

## 升级

在部署目录（仓库根目录）运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

`up -d` 会用新镜像重新创建容器；只 `restart` 跑的还是旧版本。如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.1.5`。用 1Panel 等面板升级容器时，镜像写 `:latest` 要勾选「强制拉取镜像」，或直接写 `:1.1.5`。没有新的数据库迁移。

## English summary

A patch release for v1.1.4.

- **Mermaid diagrams:** a `mermaid` code block in an answer is drawn as a diagram (flowcharts, sequence diagrams, hierarchies and the rest), in the code block's frame, with a switch between the diagram and its code, a copy button, and colours that follow the theme. It shows as code while it is being written and when it does not parse. Mermaid is loaded only for the first diagram. The system prompt tells the model such blocks are drawn and leaves the use to it.
- **Choices in generative UI:** with generative UI on, the model can end an answer with a few directions to go into next, each a message it has written in full; picking one and pressing the button sends it as the user's next message, through the usual path (moderated, guests too). Only the last answer's choices can be sent; afterwards the card stays, marking the one that was picked. Whether to offer them is left to the model.

To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

`up -d` recreates the container from the new image; a plain `restart` keeps running the old one. If `deploy/.env` pins `OPENCHAT_IMAGE` to a version, change it to `ghcr.io/qunqin24/openchat:1.1.5` first. No new database migrations.
