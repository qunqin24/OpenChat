v1.1.0 的补丁版本：修复展开思维链时网页越来越卡、甚至无响应的问题。所有 v1.1.0 部署都应升级。

*English summary below.*

## 修复

- **展开思维链时 CPU 占用越来越高。** v1.1.0 为了让流式回答更平滑，给每个字单独加了淡入动画；模型思考得越久，页面上的元素和动画就越多，主线程占用会一路涨到接近一个核，性能一般的电脑会直接卡到无响应。现在改为逐步显示已收到的文字，不再给每个字建元素：同样一段 45 秒的思维链，占用从最高约 90% 降到稳定在 20% 左右，且不再随时间上涨。大段文字一次到达时依然是平滑地逐步出现。
- 后台 设置 → 系统 →「审核」页签整页跟着滚动、内容被截在半截的问题。
- 后台「检查更新」里的升级说明改为可用的步骤：拉取新镜像后要重新创建容器（Docker Compose 用 `pull` 再 `up -d`），只重启还是旧版本。

## 升级

在部署目录（仓库根目录）运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

`up -d` 会用新镜像重新创建容器；只 `restart` 跑的还是旧版本。如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.1.1`。用 1Panel 等面板升级容器时，镜像写 `:latest` 要勾选「强制拉取镜像」，或直接写 `:1.1.1`。没有新的数据库迁移。

## English summary

A patch release for v1.1.0 that fixes the page growing slower, and freezing on weaker machines, while a long reasoning is shown open. Every v1.1.0 deployment should upgrade.

- **Fixed:** v1.1.0 faded every streamed character in as an element of its own, so a long reasoning built up thousands of nodes and animations and the main thread climbed towards a full core. Streamed text is now revealed as a growing prefix: the same 45-second reasoning stays around 20% instead of rising to about 90%, and a burst still appears smoothly.
- **Fixed:** the Admin → Settings → System → Moderation tab scrolled the whole page and cut its content off.
- **Fixed:** the upgrade hint under "Check for updates" now says to recreate the container (with Compose: pull, then `up -d`); a restart keeps the old version.

To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

`up -d` recreates the container from the new image; a plain `restart` keeps running the old one. If `deploy/.env` pins `OPENCHAT_IMAGE` to a version, change it to `ghcr.io/qunqin24/openchat:1.1.1` first. No new database migrations.
