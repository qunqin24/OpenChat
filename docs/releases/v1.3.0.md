这一版的重点是**联网读网页更准**、**可以在提问里引用其他对话**，以及**被停用的账号不再被直接踢出登录**。另外重做了输入框的「+」菜单、回复的排版和消息下方的图标，流式输出收尾更利落，登录、退出也更快。

*English summary below.*

## 新功能

- **引用其他对话。** 输入框的「+」→「引用其他对话」，可以搜索并选中自己的其他对话（一条消息最多 5 个）。它不是一份拷贝：模型回答时才去读那个对话到引用那一刻为止的问答，长对话按需分段读。输入框和发出的消息上都显示成一张小卡片，点一下打开原对话。被引用对话的标题会随这条消息一起审核。
- **「+」菜单。** 上传文件、截图（手机上没有）、从文件库添加、引用其他对话。后两项在菜单里原地换成带搜索的列表，滚到底自动加载更多。
- **读网页更准。** 模型读网页时只取正文（像浏览器的阅读模式），保留标题、列表、表格和链接，不再夹带菜单、页脚和侧栏；长页面可以接着往后读，也可以直接查找提到某个词的段落；能读 PDF（论文、财报、说明书）。
- **搜索可以限定时间和网站。** 模型可以只搜最近一天、一周、一个月或一年的内容，或只搜指定网站（如官方文档）；结果带发布日期。搜索提示词也重写了：什么时候该搜、问题拆成几个方面并行搜、优先一手来源、重要事实用两个来源印证。
- **停用账号的说明页。** 被管理员停用或因多次违规被自动封禁的账号不再被退出登录，而是看到一个页面：原因、停用时间、管理员写的说明（停用时可以填）、该联系谁；恢复后点「重新检查」即可继续使用。

## 体验改进

- 回复的排版对齐 OpenWebUI：正文字色、思考和工具行的间距与颜色、字体渲染。
- 消息下方的复制、编辑、重新生成图标换成更精致的线条图标。
- 流式输出：模型说完后很快收尾，不再拖着动画；整段一次到达的回答也会从头匀速显示，不再一下子冒出一大段。
- 请求失败重试时，提示并入「正在思考」那一行，不再单独占一行。
- 模型一次可以并行调用最多 10 个工具（原来 4 个），并会被提示尽量这样做。
- 退出登录立即回到登录页；登录页空闲时预先加载应用，登录后进入更快。
- 模型选择器里的图标不再每次打开都重新加载；Kimi 等白色标志在浅色主题下显示为深色。
- 设置里的语言选择、定时任务对话框里的下拉框换成和应用一致的样式。
- 记忆：用户的爱好和习惯也会被记住；模型不会再在没调用记忆工具的情况下说「已记住」。

## 修复

- 临时对话的欢迎页不再是黑底加一道白条。
- 回复顶部固定显示的搜索行不再盖住正文第一行。
- 新对话问候语里和当前时间对不上的那句改掉了。

## 升级

在部署目录（仓库根目录）运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.3.0`。有两个数据库迁移（记录账号被停用的原因和操作的管理员），启动时自动执行；不用改配置。

## English summary

This release makes **web page reading more accurate**, lets a message **refer to other conversations**, and **no longer signs disabled accounts out**. The composer's "+" menu, the reply layout and the message action icons are redone, streamed replies finish cleanly, and signing in and out is faster.

- **Refer to other conversations:** "+" → Reference a conversation lets you search your other conversations and pick up to 5. They are not copied: the model reads each one, up to the moment it was referred to, when it answers, reading long ones in parts. Each shows as a small card that opens the conversation. Its title is moderated with the message.
- **"+" menu:** upload files, take a screenshot (not on phones), add from the library, refer to a conversation. The last two turn the menu into a searchable list in place.
- **Better web page reading:** the model reads a page's main content as Markdown (headings, lists, tables, links) without its menus and footers. It can read a long page in parts or jump to the passages that mention something, and it can read PDFs.
- **Search by date and site:** searches can be limited to the past day, week, month or year, or to given sites, and results carry their publish dates. The search guidance in the prompt was rewritten.
- **A page for disabled accounts:** an account disabled by an administrator, or banned automatically, stays signed in and sees why, when, the administrator's note and whom to contact, with a button to check again once restored.
- **Also:** reply typography matched to OpenWebUI; finer action icons; streamed text finishes promptly and a reply that arrives whole is revealed evenly; the retry notice joins the thinking line; up to 10 tool calls run in parallel; faster sign-in and sign-out; model icons no longer reload; dark Kimi logo in the light theme; matching dropdowns in settings and the task dialog; memory keeps hobbies and habits and no longer claims to have saved without saving. Fixes for the temporary-chat welcome screen and the pinned search line covering the answer.

To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

If `deploy/.env` pins `OPENCHAT_IMAGE`, change it to `ghcr.io/qunqin24/openchat:1.3.0` first. Two database migrations (why an account was disabled, and by whom) run on start; no configuration changes.
