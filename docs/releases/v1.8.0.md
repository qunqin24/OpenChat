这一版新增**语音输入**、链接的**预览卡片**、插件操作的**「全部允许」**，以及后台模型市场的**近 6 小时**运行情况。

*English summary below.*

## 新功能

- **语音输入。** 输入框多了一个麦克风：说完后转成文字插回输入框，不会自动发送，可以先改再发。
  - 默认关闭。管理员在后台「语音输入」里打开，并选一个语音转文字模型（先支持 OpenAI 的 gpt-transcribe），可以设单段最长录音时间。
  - 按录音时长计费：模型设了每分钟价格就按分钟算；常见模型的价格已内置，没有价格的会在后台提示。用量日志里能看到每次转写的秒数和费用。
  - 录音不保存，转完即丢。App 里暂时没有麦克风，可以用系统输入法的听写。
- **链接预览卡片。** 鼠标停在回答里的链接上，会显示网页的分享图、网站名和标题；没有分享图时显示标题和摘要，再没有就显示网站名和网址。只有这个对话里搜索或读过的网页才会显示预览，其他链接只显示网址。
- **插件操作「全部允许」。** 设置里新增「权限」页，「需要确认的操作」可以从「始终询问」改成「全部允许」：之后管理员设为需要确认的插件操作直接执行，不再弹确认卡片，定时任务里也一样。管理员禁用的操作仍然不能用。
- **模型市场「近 6 小时」。** 后台模型市场新增一个标签页：每个模型一张卡片，显示近 6 小时的速度、首字延迟、成功率和状态，下面是 15 分钟一格的走势；有请求的排在前面，可以搜索，每分钟刷新。

## 改进

- 模型被删除或停用后，它以前写的回答仍显示模型的名字和图标，不再只显示模型 ID。
- 从库里删除的生成图片，在对话里显示为「已删除」，不再是一张加载不出来的图。
- 使用 Gemini 模型时，带复杂参数的插件工具不会再让整个对话的请求失败。
- 后台「系统设置」拆成单独的页面；使用日志可以按图片模型筛选。
- 内置插件的介绍改成只说插件能帮你做什么；界面上一些解释内部原理的文字去掉了。
- 后台图表点击后不再出现黑色焦点框。

## 升级

这一版有数据库迁移，启动时自动执行，部署文件没有变化。在仓库根目录运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.8.0`。

内置插件的介绍会更新成新文字；管理员自己改过的介绍保持不变。语音输入默认关闭，需要时在后台打开。

## English summary

This release adds **voice input**, **link preview cards**, an **"allow all"** setting for plugin actions, and a **last 6 hours** view in the admin's model marketplace.

- **Voice input.** A microphone in the composer turns speech into text and puts it in the composer; nothing is sent until you send it. Off by default: an administrator turns it on under "Voice input" in the admin and picks a speech-to-text model (OpenAI's gpt-transcribe for now), with a longest-recording limit. Billed by the minute where the model has a per-minute price; prices for common models are built in. Recordings are not kept. The app has no microphone yet; the system keyboard's dictation works meanwhile.
- **Link preview cards.** Hovering a link in an answer shows the page's sharing image, site and title; without an image, its title and summary; otherwise the site and address. Only pages this conversation searched or read get a preview.
- **Allow all plugin actions.** A new Permissions tab in settings switches "actions that need confirmation" from always ask to allow all: plugin actions an administrator set to confirm then run without the card, in scheduled tasks too. Actions an administrator blocked stay blocked.
- **Model marketplace: last 6 hours.** A card per model with its speed, time to first token, success rate and status over the last six hours, and its trend in 15-minute steps; busiest first, searchable, refreshed every minute.

Also: replies keep their model's name and icon after the model is removed; generated pictures deleted from the library show as deleted; plugin tools with complex parameters no longer break conversations on Gemini models; system settings have their own admin page and the usage log filters by image models; built-in plugin descriptions say what each plugin does; admin charts no longer show a focus ring when clicked.

This release has database migrations, run automatically at start; no deployment files changed. To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

If `deploy/.env` pins `OPENCHAT_IMAGE`, change it to `ghcr.io/qunqin24/openchat:1.8.0` first. Built-in plugin descriptions are updated, except ones an administrator changed. Voice input stays off until an administrator turns it on.
