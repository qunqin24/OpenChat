v1.1.0：新对话和对话页合成同一个页面，流式回答显示更平滑，被内容审核拦下的消息必须改写后才能继续对话，以及几处修复。

*English summary below.*

## 改进

- **新对话和对话页是同一个页面。** 以前在新对话页发出第一条消息时，会换到另一个页面再把消息转交过去，偶尔会闪一下，失败时还要把文字和文件送回来。现在和 OpenWebUI 一样：发第一条消息时页面不动，只是地址在服务器接收后变成 `/chat/…`；被拒绝时文字和文件原样留在输入框里。新对话页不再留在浏览器历史里，「返回」会回到更早的页面。第一条消息还在发送时点「新对话」，会立刻回到空白页，那条消息在后台照常发完。
- **流式回答不再突然冒出一大段。** 回答是一批一批到达浏览器的，遇到服务器写库慢、反向代理或中转站把内容攒着、标签页从后台切回来时，一批会很大，以前会整段跳出来。现在每个字淡入，一批里的字依次显现，读起来像在打字；回答结束时排队的字也会放完，不会在最后一下子出现。
- **被拦下的消息必须改写才能继续。** 以前被拦下后，随便再发一句（比如「。」）对话就接着往下走，模型像是回答了它根本没看到的内容。现在对话末尾是被拦下的消息时，输入框变成这条消息的编辑器：上方有一行提示，里面预填被拦下的原文，输入框里的文件一并带上；改写通过审核后对话才继续。这期间发送、重新生成、回答模型的提问都会被拒绝（`revise_refused`）。再次被拦下时，新措辞替换旧的那一条。游客模式同样生效。

## 修复

- 对话不再一直叫「新对话」。以前只有回答正常完成后才起标题，回答被停止、失败，或起标题的模型出错、超时就放弃了；现在回答怎么结束都会起标题，模型起不出来就用提问的第一行。
- 后台使用日志的「输出速度」按整个请求的时长计算。以前对推理模型只按开始输出文字之后的时间算，会出现每秒几万 token 这种不可能的数字；输出太少、太快、失败或估算的请求不再显示速度。
- 引用来源中没有图标的网站不再在浏览器控制台里留下一串 404 报错，页面照旧显示首字母圆标。

## 升级

```bash
docker pull ghcr.io/qunqin24/openchat:1.1.0
```

替换镜像后重启即可，没有新的数据库迁移。

## English summary

- **One page for a new chat and the conversation it becomes.** Sending the first message no longer moves to another page and hands the message over: the page stays, and the address becomes `/chat/…` once the server has taken the message, as in Open WebUI. A refused first message leaves its text and files in the composer; the new-chat screen is no longer a step in the browser history; "New chat" while a first message is still being sent goes straight back to an empty page and the message is sent in the background.
- **Streamed answers no longer jump in large blocks.** Each character fades in and a burst is spread over time, so a slow commit, a buffering proxy or relay, or a tab back from the background reads as typing; the queue finishes when the answer ends.
- **A refused message must be reworded before the conversation goes on.** While the last message is one moderation refused, the composer becomes its editor (a note above it, the refused text inside, files carried along); sending, regenerating and answering the model's question are refused (`revise_refused`) until it is reworded, and words refused again replace it. Guests too.
- **Fixes:** a conversation no longer stays "New chat" when its answer was stopped or failed, or the title model failed or timed out (the question's first line names it then); the usage log's output speed is measured over the whole request (reasoning models showed impossible figures) and is hidden when there is too little to measure; a cited site without an icon no longer leaves a 404 in the browser console.
