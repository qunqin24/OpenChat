这一版修复**带两张及以上图片的消息发不出去**的问题（开着 OpenAI 内容审核时），并换上新的「模型在工作」动画。

*English summary below.*

## 修复

- **带多张图片的消息不再被当成「内容审核暂时不可用」拦下。** OpenAI 的审核接口一个请求只收一张图，两张就回 400（`too_many_images`），以前把消息里的图片放进同一个请求，于是开着「审核出错时拦下」的站点，发两张图必定失败。现在每张图单独一个请求、同时发出，任何一张没审过都不放行。带图的请求超时也从 5 秒放宽到 30 秒：一张 4 MB 的图实测要 4 到 12 秒，原来大图偶尔也会超时。

## 改进

- **模型在工作时，用点阵球表示它在做什么。** 原来的九点波浪换成 [Thinking Orbs](https://github.com/yogesharc/thinking-orbs) 的点阵球（MIT），按它在做的事换样子：思考、搜索、读网页、读文件、写作、重试、压缩上下文、等你回答、子 Agent 在跑各有一种。侧栏里在后台运行的对话、写作块卡片上也是它。思考结束后「已思考 N 秒」前面和输入框的「思考」按钮上是一个静止的球。系统开了「减少动态效果」时它照样动，和其他加载指示器一样。
- **回答的过程默认收起。** 模型思考、调用工具时不再自动展开过程，标题和点阵球会说明它在做什么，想看再点开；工作中点开的，答案开始时自动收起。

## 升级

在部署目录（仓库根目录）运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.4.2`。没有数据库迁移，不用改配置。

## English summary

This release fixes **messages with two or more images failing to send** when OpenAI moderation is on, and brings a new "model at work" indicator.

- **Messages with several images are no longer refused as "moderation unavailable":** OpenAI's moderation endpoint takes one image per request and answers two with 400 `too_many_images`, and all of a message's images went in one request, so a site set to block on moderation errors refused every message with two pictures. Each image now goes in its own request, all at once, and the message passes only if every one was checked. Requests carrying an image get 30 seconds instead of 5: a 4 MB picture took 4 to 12 seconds, so large single images could time out too.
- **A dot sphere shows what the model is doing:** the nine-dot wave is replaced by the dot sphere from [Thinking Orbs](https://github.com/yogesharc/thinking-orbs) (MIT), with a look for each thing the model does: thinking, searching, reading a page or a file, writing, retrying, compacting the context, waiting for your answer, running sub-agents. It also marks conversations running in the sidebar and the writing-block card. Finished thinking and the composer's thinking button show it still. It keeps moving under reduced motion, like the other loading indicators.
- **The reply's process stays folded:** it no longer opens by itself while the model thinks or calls tools; its title and the sphere say what is happening, and it opens on a click. Opened mid-run, it folds away when the answer starts.

To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

If `deploy/.env` pins `OPENCHAT_IMAGE`, change it to `ghcr.io/qunqin24/openchat:1.4.2` first. No database migrations and no configuration changes.
