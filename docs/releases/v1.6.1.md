这一版修复**定时任务还没运行，侧栏就出现它的空对话**。

*English summary below.*

## 修复

- **定时任务的对话在第一次运行后才出现在侧栏。** 每个定时任务有一个专属对话，在创建任务时就建好了，所以任务还没到点，侧栏的对话列表和搜索里就已经有一个空对话。现在，这个对话在任务第一次运行之前不会出现在侧栏，运行后排到最上面。「定时任务」页的「打开对话」照常能进入。

## 升级

这一版没有数据库迁移，也不用改配置。在仓库根目录运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.6.1`。

## English summary

This release fixes **a scheduled task's empty conversation showing in the sidebar before the task has run**.

- A task's conversation is made with the task, so it appeared, empty, in the sidebar's list and search before its first run. It is now left out until the task first runs, then appears at the top. The tasks page still opens it.

No database migrations and no configuration changes. To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

If `deploy/.env` pins `OPENCHAT_IMAGE`, change it to `ghcr.io/qunqin24/openchat:1.6.1` first.
