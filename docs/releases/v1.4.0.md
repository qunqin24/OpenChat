这一版重做了**回复过程的显示**：模型在给出答案之前做的事（思考、路上说的话、搜索和读网页）收进一个折叠块，像 ChatGPT 那样；另外加了**对话导航**，长对话里可以一眼看到问过什么、点一下跳过去。

*English summary below.*

## 新功能

- **回复过程收进一个折叠块。** 答案之前的思考、模型路上说的话和每一步工具调用都收在一起，标题只写「已思考 N 秒」。模型工作时自动展开，答案一开始就自动收起，随时可以自己点开。展开后：
  - 模型路上说的话（「我来查一下……」）照答案的样子显示，里面的图表、卡片、选项等智能 UI 也照常画出来；
  - 两句话之间的思考和工具调用各收成一行，比如「已思考 6 秒，搜索了 3 次」，点开才是思考原文和每一步；
  - 思考进行中只露最新几行，不会把后面的内容推出一屏；思考完的长段落是一个可以单独滚动的框。
- **对话导航。** 对话区右边一排短横线，一条代表你问的一句话，正在读的那条颜色更深；鼠标靠近时展开，悬停显示那句问题和回答开头，点击跳到那里。右侧空白不够、旁边开着面板或对话少于两轮时不显示。

## 体验改进

- 思考的图标换成不带光芒的灯泡，并放大到和其他图标一样大。
- 回复过程的标题不再吸在顶部（之前在快速滑动、段尾和内外层交接时会出现重叠或露底）。

## 修复

- 模型读取写作块时，不再一闪而过「正在修改……」的卡片。
- 账号在打开对话期间被停用时，页面会转到停用说明页，不再在后台不停重连。

## 升级

在部署目录（仓库根目录）运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.4.0`。有一个数据库迁移（记录一次回复是否从手机 App 发起，为即将发布的 Android App 准备），启动时自动执行；不用改配置。

## English summary

This release redoes **how a reply's process is shown**: everything the model did before its answer (its thinking, what it said on the way, its searches and page reads) is one fold, as in ChatGPT. It also adds a **conversation navigator** that shows at a glance what was asked in a long conversation and goes there in a click.

- **The process in one fold:** the thinking, the words the model said on its way and every tool call sit together under one line, "Thought for N seconds". It opens by itself while the model works and closes when the answer starts; the reader can open it at any time. Inside, what the model said on its way reads as the answer does, interface blocks (charts, cards, choices) included; the thinking and steps between those words fold into lines of their own ("Thought for 6 seconds, searched 3 times"); a thought being written shows its last lines, and a finished long one is a box that scrolls.
- **Conversation navigator:** a row of short lines at the transcript's right edge, one per question, the one being read darker. They draw out as the pointer comes near; pointing at one shows the question and the start of its answer, and clicking goes there. Hidden when the margin is too narrow, a side panel is open, or there are fewer than two questions.
- **Also:** the thinking mark is a bulb without rays, drawn as large as the other icons; the process line no longer pins to the top while scrolling (it overlapped or let text show through when scrolling fast). Fixes: reading a writing block no longer flashes the "editing" card, and an account disabled while a conversation is open goes to the disabled-account page instead of reconnecting in the background.

To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

If `deploy/.env` pins `OPENCHAT_IMAGE`, change it to `ghcr.io/qunqin24/openchat:1.4.0` first. One database migration (whether a reply was started from the phone app, for the Android app to come) runs on start; no configuration changes.
