这一版主要是安全修复：**打开 Word 文件时，文件里内嵌的网页脚本可能被执行**，以及没发出去的上传文件可以绕过存储上限。另外修了长文件和 Excel 的几处读取问题，换了设置页的外观选择、新对话页的问候和图标。建议所有人升级。

*English summary below.*

## 安全修复

- **Word 预览不再执行文件里的脚本。** 以前一个精心制作的 Word 文件（内嵌 HTML）在页面里打开时，里面的脚本会以当前用户的身份运行。现在 Word 页面画在一个不允许运行脚本的隔离框里，不再显示内嵌的 HTML，链接只保留网页、邮件和文内跳转，并在新标签打开。
- **上传不能超过声明的大小。** 以前上传时声明的大小和实际写入的大小没有绑定，没发出去的文件可以比计入存储上限的大得多。现在本地存储按声明的大小截断，对象存储的上传链接把文件长度签进了签名，大小不符会被拒绝。

## 修复

- 很长的单行文件（压缩过的 JSON、HTML 等）现在模型能分段读完，以前只能读到开头；在文件里搜索时，长行显示命中位置附近的内容。
- Excel：名字里带逗号的工作表（如「Sales, 2026」）不再消失；内容恰好像工作表标题的单元格不再被当成新工作表；表格中间的空行保留，行号和 Excel 一致；第 500 行以后才出现的列也会显示。

## 体验改进

- 设置页：左侧标签不再发灰，选中的加深加粗；「主题」改为三张小卡片，每张画着那个主题下的界面。
- 新对话的问候每次换一句：按时段有几句平实的、带名字的、俏皮的，周一、周五、周末另有几句，元旦、圣诞等节日当天说节日的话。
- 新对话的建议和定时任务的示例换上专门画的图标，不再用 emoji。

## 升级

在部署目录（仓库根目录）运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.2.2`。没有数据库迁移，不用改配置。

## English summary

Mainly security fixes: **a Word file opened in the page could run scripts embedded in it**, and an upload never sent could get past the storage quota. Also fixes reading long files and workbooks, and refreshes the appearance picker, the new-chat greeting and some icons. Upgrading is recommended.

- **Word previews no longer run a file's scripts:** a crafted .docx with embedded HTML could run script as the person viewing it. Pages are now drawn in a frame that may not run scripts, embedded HTML is not shown, and links keep only web, mail and in-document targets, opening in a new tab.
- **Uploads are held to their announced size:** the size counted against the quota was not tied to what was stored, so a file never sent could be far larger. The local driver cuts the upload off at that size, and a bucket's presigned URL has the length signed in.
- **Fixes:** a very long single line (minified JSON or HTML) can now be read to its end by the model, and a search shows a long line around the match; workbook sheets with a comma in their name no longer vanish, a cell that looks like a sheet heading stays a cell, blank rows inside a sheet keep Excel's row numbers, and columns that first appear after row 500 are shown.
- **Also:** readable settings tabs and a theme picker of three small pictures; a greeting that changes each time, with lines for the time of day, weekdays and holidays; drawn icons for the new-chat starters and the scheduled-task ideas.

To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

If `deploy/.env` pins `OPENCHAT_IMAGE`, change it to `ghcr.io/qunqin24/openchat:1.2.2` first. No database migrations, no configuration changes.
