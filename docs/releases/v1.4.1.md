这一版修复一个显示问题：**展开含有 Mermaid 图表的内容（比如思考）时，窗口右边会突然冒出一条很长的滚动条，图画完又消失**。

*English summary below.*

## 修复

- **画图表时不再冒出滚动条。** Mermaid 画图时会先在页面最底部放一张临时的图来排版，过好几步才删掉；这段时间里整个页面被多撑出一张图的高度，窗口就多了一条自己的滚动条。现在图在一个固定定位、看不见的容器里排版，页面高度不变，画出来的图和原来一样。

## 升级

在部署目录（仓库根目录）运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.4.1`。没有数据库迁移，不用改配置。

---

## English summary

This release fixes a glitch: **opening something with a Mermaid diagram in it (a thought, say) made a long scrollbar flash at the window's edge until the diagram was drawn**.

- **No scrollbar while a diagram is drawn:** Mermaid laid each diagram out in a temporary node at the end of the page and kept it there across several steps, so the page grew by the diagram's height and the window showed a scrollbar of its own. Diagrams are now laid out in a fixed, hidden container: the page keeps its height and the diagrams come out the same.

To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

If `deploy/.env` pins `OPENCHAT_IMAGE`, change it to `ghcr.io/qunqin24/openchat:1.4.1` first. No database migrations and no configuration changes.
