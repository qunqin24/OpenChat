这一版新增**参考聊天记录**：新对话能接上你之前聊过的事，模型也能翻找你以前的对话。另外改进了表格查看、升级后的页面提示和界面的圆角。

*English summary below.*

## 新功能

- **参考聊天记录。** 新对话会带上你最近对话的清单——日期、标题和你自己说过的话（截短的原文，不是摘要）。说「接着昨天那个」「刚才那个计划」，模型直接就知道指的是什么。更早的对话，或者模型当时给出的具体内容，模型会用新的 `chat_history` 工具按关键词搜你的全部历史、读出命中的前后文，回复里会显示「搜索了聊天记录」，点开能跳到那个对话。
  - 默认开启。个性化设置里「记忆」下面有单独的开关，后台「系统设置」里有总开关，两者都开才生效。
  - 临时对话不读也不会被读到。删除一个对话后，它会立即从其他对话的清单里消失。
  - 你改过的对话标题会先经过内容审核，才会出现在清单里；模型起的标题不需要。
  - 子 Agent 和深度研究不使用这个功能，定时任务可以。

## 改进

- **表格查看更稳定。** 在侧边面板里看 Excel、CSV 时，滚动不再让列忽宽忽窄；单元格里的长内容会按列宽自动换行（最多 12 行，悬停看全文），几千行的表格仍然流畅。
- **升级后的提示。** 服务端升级后，没有刷新的旧页面在打开某些内容（Word、PDF、设置页的部分标签、后台页面）时不再进入错误页，而是提示「页面有一部分没能加载」并给出刷新按钮；输入框里没发出的内容不受影响。
- **更圆润的圆角。** 输入框、消息气泡、卡片、对话框等较大的圆角改为连续曲率（Chrome、Edge 139 及以上可见，其他浏览器保持原样）。
- 过期的登录会话现在会被定期清理。
- 后台用户列表去掉了不起作用的「角色」筛选，表头去掉了不起作用的排序菜单。

## 移除

- 个性化设置里一直显示「即将推出」的「从对话中学习」开关已移除：这个功能不再开发，接上以前对话的需求由参考聊天记录满足。
- 管理接口 `GET /admin/catalog/providers`，以及 `/admin/catalog/models` 的 `providerId`、`capability` 参数（没有客户端使用）。

## 升级

这一版有数据库迁移，启动时自动执行，部署文件没有变化。在仓库根目录运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.7.0`。

参考聊天记录默认对所有人开启。如果暂时不想启用，升级后在后台「系统设置」里关掉总开关即可。App 里的开关和工具显示会在下一个 App 版本里提供；在那之前，App 用户的设置仍可在网页里修改。

## English summary

This release adds **reference chat history**: a new conversation picks up what you talked about before, and the model can look through your earlier conversations.

- A new conversation carries a list of your recent conversations — date, title and your own words, shortened verbatim, not summarised — so "carry on with yesterday's plan" just works. For older conversations, or what the model said at the time, the model searches your whole history with the new `chat_history` tool and reads the matches in context; the reply shows the search and links to the conversations it found.
- On by default, with its own switch under Personalization and a master switch in the admin's system settings. Temporary chats neither read nor appear in it; a deleted conversation drops out of every list at once; renamed titles are moderated before they are listed. Not used by sub-agents or deep research; scheduled tasks may use it.

Also: the spreadsheet viewer keeps its columns steady while scrolling and wraps long cells (up to 12 lines); a page left open across an upgrade offers a reload instead of an error screen when it cannot load part of itself; larger corners use continuous curvature where the browser supports it; expired sessions are purged; the admin users table loses a role filter and sort menus that did nothing.

Removed: the never-working "learn from conversations · coming soon" switch, and the unused admin endpoint `GET /admin/catalog/providers` and the `providerId` and `capability` parameters of `/admin/catalog/models`.

This release has database migrations, run automatically at start; no deployment files changed. To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

If `deploy/.env` pins `OPENCHAT_IMAGE`, change it to `ghcr.io/qunqin24/openchat:1.7.0` first. To keep reference chat history off for now, turn off its switch in the admin's system settings after upgrading. The app's switch and tool display come with the next app release; until then, app users can change the setting on the web.
