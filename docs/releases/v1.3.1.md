这一版主要是网页的观感：**流式回答改成一批一批淡入**，Markdown 表格换成更清爽的样式，上下文窗口的弹层和子智能体的动画也顺了一遍。服务端同时为即将推出的 Android App 做好了准备（App 登录、通行密钥），App 本身之后单独发布。

*English summary below.*

## 体验改进

- **流式回答整批淡入。** 文字一到就显示，同一批到达的字一起在 0.6 秒内淡入，不再一个字一个字地打出来，也不会因为等节奏而落在实际收到的内容后面。淡入是盖在文字上的一层，不管回答多长都只多几个元素，长思维链也不会变卡；系统开了「减少动态效果」时直接显示。
- **Markdown 表格。** 去掉外框、底色和竖线：表头下一条细线，行与行之间一条更淡的线，表格撑满正文宽度，单元格保留 Markdown 里写的对齐方式。界面块里的表格不变。
- **上下文窗口。** 点击输入框旁的圆环，弹出的是和悬停提示一样的深色小卡片，不再是白色菜单。
- **子智能体的动画。** 运行中那朵花转一圈的首尾现在接得上，不再每转一下花瓣就同时跳一次。

## 管理员

- 后台「身份验证」→ 通行密钥里可以登记 Android App（包名和签名证书的 SHA-256 指纹），服务器据此提供 `/.well-known/assetlinks.json` 并接受来自这些 App 的通行密钥。只用网页版的部署不用管它。

## 升级

在部署目录（仓库根目录）运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.3.1`。没有数据库迁移，不用改配置。

## English summary

This release is mostly about how the web app looks: **streamed answers now fade in a batch at a time**, Markdown tables get a cleaner style, and the context meter's popup and the sub-agent animation are smoothed out. The server is also ready for the upcoming Android app (app sign-in, passkeys); the app itself ships separately later.

- **Streamed answers fade in by batch:** text shows as soon as it arrives, and everything that arrived together fades in over 0.6 s, instead of being typed out character by character behind what was received. The fade is a layer over the text, so a long answer or reasoning adds only a few elements; with reduced motion the text simply appears.
- **Markdown tables:** no frame, fill or column rules; a hairline under the header and fainter ones between rows, the full width of the column, and each column's alignment kept. Tables in interface blocks are unchanged.
- **Context meter:** clicking the ring opens the same dark chip as its tooltip rather than a white menu.
- **Sub-agent animation:** the turning flower's loop now joins up instead of every petal jumping at the seam.
- **Administrators:** Authentication → Passkeys can register Android apps (package name and signing certificate SHA-256), which the server publishes in `/.well-known/assetlinks.json` and accepts passkeys from. Web-only deployments can ignore it.

To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

If `deploy/.env` pins `OPENCHAT_IMAGE`, change it to `ghcr.io/qunqin24/openchat:1.3.1` first. No database migrations and no configuration changes.
