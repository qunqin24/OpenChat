## 新功能

- **Word、Excel、PDF。** 现在可以附加 Word（.docx）和 Excel（.xlsx），任何模型都能读：服务器把它们读成文字发给模型（Word 转成带标题、列表、表格的 Markdown，Excel 每个工作表一段表格），原件照常保存，文件库里下载的还是原件。不能读 PDF 的模型现在也能收 PDF（发的是文字，每页标明页码）；能读 PDF 的模型在 20 页以内仍然收原件，更长的改发文字。扫描件对能读 PDF 的模型发原件。
- **长文件按需读取。** 超过 16 KB 的文本、文档和 PDF 不再整篇塞进每一轮对话，模型只看到开头和目录，需要时用「读取某几行」「在文件里搜索」两个工具去读。具体问题能省下大部分费用；搜索能找到 PDF 里被换行拆开的词句。模型不能调用工具时照旧整篇发送。
- **在页面里打开文件。** Word 按原排版显示（字体、颜色、表格、图片、分页），PDF 逐页显示，Excel 和 CSV 显示成带工作表、列号、行号的表格（几千行也不卡），Markdown 渲染成格式。在对话里点开是侧栏，在文件库里点开是全屏。
- **存储上限。** 每个人的文件加起来默认最多 5 GB，满了就不能再上传，删掉一些文件后恢复。设置 →「数据」显示已用多少、各类文件各占多少。管理员在 后台 → 文件存储 改默认上限，在 后台 → 用户 给某个人单独设置，用户列表里能看到每个人的用量。
- **对话置顶。** 侧栏对话的「…」菜单里可以置顶，置顶的对话固定在侧栏最上面。
- **新的新对话页。** 输入框放在页面正中，上方是按时间变化的问候（「下午好，你的名字」，深夜是「夜深了」），下方是几个开头建议；发送后输入框平滑移到底部。手机上输入框仍在底部。
- **图片搜索可以设多个来源。** 后台「图片搜索」里可以勾选多个服务并排序，一个不可用或没找到就自动换下一个；遇到服务临时故障会自动重试。新增 Bing 图片作为可选来源（默认不开：非官方接口，图片版权归原网站）。

## 体验改进

- 文件卡片重新设计：浅灰底加彩色角标（DOCX、XLSX、PDF、MD），第二行写文件类型和大小；文件库的卡片显示文件开头内容的预览，并新增「文档」筛选。
- 发送消息时附件立刻从输入框清走，发送失败再放回去。
- 隔了一段时间显示的时间标签改为居中。
- 模型在两次工具调用之间等待时，活动栏显示刚完成的那一步，而不是「正在思考」。

## 修复

- PDF 里的文字以前没有经过内容审核，现在和消息一起审。
- 上传声明的大小和实际不符时，按实际大小计算。

## 升级

在部署目录（仓库根目录）运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

`up -d` 会用新镜像重新创建容器；只 `restart` 跑的还是旧版本。如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.2.1`。用 1Panel 等面板升级时，镜像写 `:latest` 要勾选「强制拉取镜像」，或直接写 `:1.2.1`。

**运行镜像改为 Alpine。** 为了读取 PDF 文字，镜像里加了 poppler。首次拉取比以前多大约 20 MB，之后升级只拉程序那一层。程序仍以 uid 65532 运行，数据卷不用改权限。

**存储上限立即生效。** 默认每人 5 GB。已经超出的账号不会被删任何文件，但要删掉一些文件后才能继续上传；需要的话先在 后台 → 文件存储 调高默认值，或在 后台 → 用户 单独设置。

**PDF 内容开始审核。** 开着内容审核时，PDF 里的文字也会被检查，以前能发的 PDF 现在可能被拦下。

**有 2 个数据库迁移**，启动时自动执行：存储上限、对话置顶。

**许可证改为 GNU AGPL-3.0。** v1.2.0 及更早的版本仍按发布时的 MIT 许可证提供。按 AGPL，向用户提供网络服务时需要提供对应的源代码。

## English summary

Word, Excel and PDF files now reach every model and open in the page; long files are read in parts instead of being resent on every turn; each person has a storage quota; conversations can be pinned; and the new-chat page is redesigned. **The runtime image is now Alpine, and the license is now AGPL-3.0** — see Upgrading below.

- **Word, Excel and PDF:** attach .docx and .xlsx for any model, sent as their words (Word as Markdown, Excel as a table per sheet); the original is kept and downloads as itself. A model that does not read PDFs now gets a PDF's text with page markers; one that does still gets PDFs of up to 20 pages whole, longer ones as text; scanned PDFs go whole where they can.
- **Long files read in parts:** text, documents and PDFs over 16 KB are shown to the model as their beginning and headings, with tools to read a range of lines and search the file (matching across a PDF's line breaks). Models without tools still get the whole file.
- **Opening files:** Word laid out as Word lays it out, PDFs page by page, Excel and CSV as sheet grids (fast with thousands of rows), Markdown rendered; beside the conversation, or full screen from the library.
- **Storage quota:** 5 GB per person by default; uploads past it are refused until files are deleted. Settings → Data shows the usage by kind. Administrators set the default under File storage and per person under Users, which also shows each person's usage.
- **Pinned conversations** from the sidebar menu, kept at the top of the sidebar.
- **New-chat page:** the composer in the middle under a greeting for the time of day, starters below it; sending glides the composer to the foot. On phones the composer stays at the foot.
- **Image search** asks several services in the order chosen, moving on when one is down or finds nothing, with retries on brief outages; Bing Images is a new, optional source (off by default: unofficial, and its pictures keep their sites' rights).
- **Also:** redesigned file cards with type badges and library previews with a Documents filter; sent files leave the composer at once; the pause time is centred; the activity line names the step just done while the model is between steps.
- **Fixes:** PDF text is now checked by content moderation; uploads are counted at their stored size.

To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

`up -d` recreates the container from the new image; a plain `restart` keeps running the old one. If `deploy/.env` pins `OPENCHAT_IMAGE` to a version, change it to `ghcr.io/qunqin24/openchat:1.2.1` first.

**Alpine runtime image:** poppler is added to read PDF text; the first pull is about 20 MB larger, later upgrades pull only the app layer; the server still runs as uid 65532. **The storage quota applies at once:** 5 GB by default; accounts already over it keep every file but cannot upload until they delete some — raise the default or set a person's own quota first if needed. **PDF text is now moderated** when moderation is on, so some PDFs that went through before may be refused. **Two database migrations** run at startup: storage quota, pinned conversations. **License:** OpenChat is now under the GNU AGPL-3.0; releases up to v1.2.0 remain available under the MIT license they were published with.
