这一版修复**升级到 1.5.0 之后，用 Claude 的老对话每条消息都报「模型出错」**的问题，并减少之后再出现这种情况的机会。

*English summary below.*

## 修复

- **用 Claude 的对话不会再因为思考块的签名被拒而一直失败。** Anthropic 现在把每个思考块绑定在它之前的系统提示词、工具和消息上，其中任何一处变了，整个请求就被拒（`Invalid signature in thinking block. The block is bound to a different conversation`）。升级会改系统提示词和工具，所以 1.5.0 之前的 Claude 对话升级后每条消息都失败。开关联网、在 App 和网页之间换着发、对话被压缩，也会触发同样的错误。
  - 现在每个思考块都记下它之前的内容。只有这些内容还和当时一样，才会把它发回去，其余的不发，请求照常进行。代价是那部分之前的思考模型看不到了，缓存也要重建。
  - 仍然被拒时，自动去掉思考块再发一次。这种拒绝不产生内容，也不计费。
  - 升级前存下的思考块一律不再发回，已经卡住的对话升级后就能恢复。
- **写作块的改动说明不再重复。** 说明只讲上次告诉模型之后的新改动；说明里讲过的版本也算模型看过，整篇重写时不会因此被拒。

## 改进

为了减少思考被丢掉的次数，几处会在两次回答之间改动内容的地方改成了不变：

- 写作块改动、子 Agent 状态、插件变化这些「轮次说明」，存进数据库，之后每次请求都原样附在原来那条消息上。
- 从 App 发的消息，「按手机屏幕排版」的说明附在这条消息上，不再放进系统提示词，在 App 和网页之间换着发不会改动之前的内容。
- 读长文件的两个工具，只要模型能调工具就始终提供，不会在第一次上传长文件时才出现。

## 升级

这一版有两个数据库迁移，启动时自动执行。在仓库根目录运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.5.1`。不用改配置。

## English summary

This release fixes **Claude conversations from before 1.5.0 failing on every message after the upgrade**, and makes it less likely to happen again.

- **Claude conversations no longer fail over thinking-block signatures.**
  - Anthropic binds each thinking block to the system prompt, tools and messages before it, and refuses the whole request when any of them changed. An upgrade changes the prompt and tools, so older Claude conversations failed on every message. Switching web search, moving between the app and a browser, or a compressed history did the same.
  - Each thinking block now records what came before it and goes back only while that still holds. The rest are left out, which costs that thinking and a cache rebuild.
  - A request refused all the same is retried once without thinking. The refusal produces nothing and is not billed.
  - Thinking stored before this release is left out, so stuck conversations work again.
- **Writing-block edit notes no longer repeat.** A note tells only what changed since the last version told, and a whole rewrite over a version a note told is not refused.
- **Fewer changes to earlier context:**
  - Turn notes are kept and sent with their message on every later request.
  - The phone app's layout note rides on its message instead of the system prompt.
  - The long-file tools are always offered to models that call tools.

To upgrade, from the repository root (two database migrations run at start, no configuration changes):

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

If `deploy/.env` pins `OPENCHAT_IMAGE`, change it to `ghcr.io/qunqin24/openchat:1.5.1` first.
