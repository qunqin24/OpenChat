这一版改进**回答中途停顿后突然冒出一大段**的显示，并去掉两处容易误操作的地方。

*English summary below.*

## 改进

- **上游停顿后，剩下的内容不再一下子冒出来。** 模型服务偶尔会在回答中途停几秒，再把剩下的一次发过来。之前这一大段会立刻全部显示，看起来像页面卡了。现在它按停顿前的出字速度从上往下流出来，最多 2.5 秒流完。正常出字时和原来一样。
- **回答停住时显示「仍在生成…」。** 回答中途超过 2 秒没有新内容，下方会出现和「思考中」同样的提示，有新内容就消失。网页和 App 都有。

## 调整

- 网页上 Markdown 表格右上角的复制按钮去掉了，复制整条回答时表格会一起复制。
- 网页上的图片不能再拖动。之前在 Chrome 和 Safari 里拖动对话中的图片，会弹出「添加文件」的遮罩，松手后还会把图片当附件加进去。

## 升级

这一版没有数据库迁移，也不用改配置。在仓库根目录运行：

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

如果在 `deploy/.env` 里用 `OPENCHAT_IMAGE` 固定了版本号，先改成 `ghcr.io/qunqin24/openchat:1.5.2`。

## English summary

This release smooths **the rest of an answer arriving all at once after a pause**, and removes two easy misclicks.

- **Text after a stall flows in.** A model provider sometimes goes quiet for seconds part-way through an answer and then sends the rest at once, which used to jump onto the page and look like a hang. It now flows in at the speed text was coming before the pause, within 2.5 seconds at most. Normal streaming is unchanged.
- **"Still writing…" while an answer is stalled.** After 2 seconds with nothing new, the same line as "Thinking…" appears below the answer, on the web and in the app.
- On the web, Markdown tables no longer have a copy button (copying the answer copies its tables), and pictures can no longer be dragged — in Chrome and Safari a dragged picture opened the drop overlay and could be attached by mistake.

No database migrations and no configuration changes. To upgrade, from the repository root:

```bash
docker compose -f deploy/docker-compose.yml --env-file deploy/.env pull openchat
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d
```

If `deploy/.env` pins `OPENCHAT_IMAGE`, change it to `ghcr.io/qunqin24/openchat:1.5.2` first.
